
# Текстовый калькулятор

Калькулятор для вычисления арифметических выражений, записанных словами на русском языке.

Пример:

Ввод: `двадцать пять плюс тринадцать`

Вывод: `тридцать восемь`

## Архитектура проекта

Программа разделена на независимые модули. Каждый модуль отвечает за отдельный этап обработки выражения.

### Структура проекта

```text
text-calculator/
```

### 1. number_parser.py

**Функция:** `parse_number(text)`

**Назначение:** преобразование числительных на русском языке в целые числа.

- Вход: `text` — строка (`str`).
- Выход: целое число (`int`).
- Диапазон: от 0 до 99.
- Поддерживается ввод без учёта регистра.
- При некорректном вводе вызывается `ValueError`.

**Пример:**

`parse_number("сорок пять")` → `45`

**Используемые словари:**

- `UNITS` — единицы от 0 до 9.
- `TEENS` — числа от 10 до 19.
- `TENS` — десятки от 20 до 90.

### 2. number_formatter.py

**Функция:** `number_format(number)`

**Назначение:** преобразование целых чисел в русские числительные.

- Вход: `number` — целое число (`int`).
- Выход: текстовое представление числа (`str`).
- Текущий диапазон: от -9999 до 9999.
- Поддерживаются отрицательные числа и ноль.
- При неподдерживаемом типе или диапазоне вызывается `ValueError`.

**Пример:**

`number_format(-579)` → `"минус пятьсот семьдесят девять"`

**Основные переменные:**

| Переменная | Назначение |
|---|---|
| `number` | Оставшаяся необработанная часть числа |
| `result` | Список слов для формирования результата |
| `divisor` | Текущий разряд: 1, 10, 100 или 1000 |
| `digit` | Цифра текущего старшего разряда |
| `key` | Значение разряда для поиска в словаре |

**Принцип работы:**

1. Проверяется тип входного значения.
2. Отдельно обрабатываются ноль и отрицательные числа.
3. Определяется старший разряд числа.
4. Через целочисленное деление `//` выделяется цифра разряда.
5. С помощью `divisor * digit` формируется ключ словаря.
6. Найденное числительное добавляется в `result`.
7. Через `%` определяется оставшаяся часть числа.
8. Цикл повторяется до полной обработки числа.
9. Список объединяется в строку через `' '.join(result)`.

Числа от 10 до 19 обрабатываются отдельно, так как имеют особые названия.

### 3. expression_parser.py

**Статус:** планируется.

**Назначение:** разбор текстового выражения на числа, операторы и скобки.

Планируемый пример:

`"двадцать пять плюс три"` → `[25, '+', 3]`

### 4. rpn.py

**Статус:** планируется.

**Назначение:** преобразование арифметического выражения в обратную польскую нотацию (ОПН).

Модуль будет учитывать приоритет операций и скобки.

Пример:

`[25, '+', 3, '*', 2]` → `[25, 3, 2, '*', '+']`

### 5. calculator.py

**Статус:** планируется.

**Назначение:** вычисление выражения в обратной польской нотации с помощью стека.

Пример:

`[25, 3, 2, '*', '+']` → `31`

### 6. main.py

**Основная функция:** `calc(text)`

**Статус:** в разработке.

**Назначение:** объединение всех модулей в единую программу.

Планируемый интерфейс:

- Вход: текстовое арифметическое выражение (`str`).
- Выход: результат вычисления словами (`str`).

Пример:

`calc("двадцать пять плюс тринадцать")` → `"тридцать восемь"`

## Общий алгоритм

1. Получить математическое выражение в виде строки.
2. Разделить выражение на числительные, операторы и скобки.
3. Преобразовать числительные в целые числа.
4. Построить обратную польскую нотацию.
5. Вычислить результат с помощью стека.
6. Преобразовать результат в русское числительное.
7. Вернуть итоговую строку.

## Поддерживаемые возможности

### Базовая функциональность

- Числительные от 0 до 99 на входе.
- Сложение.
- Вычитание.
- Умножение.
- Результат в виде русского числительного.

### Планируемые расширения

- Несколько арифметических операций в одном выражении.
- Приоритет арифметических операций.
- Скобки.
- Отрицательные числа.
- Диагностика ошибок ввода.
- То есть общая сложность где-то 8-9.

## Обработка ошибок

При некорректных входных данных модули вызывают `ValueError`.

Планируется централизованная обработка ошибок в основном модуле, чтобы пользователь получал понятное сообщение вместо аварийного завершения программы.
