# Текстовый калькулятор

Консольный калькулятор для вычисления арифметических выражений, записанных словами на русском языке. Программа преобразует текст в математические токены, учитывает приоритет операций и скобки, вычисляет результат и записывает его словами.

**Пример:**

```text
Введите выражение: скобка пять плюс три скобка умножить минус два
минус шестнадцать
Введите выражение: конец
```

## Возможности и ограничения

- Числа на входе — от **0 до 99**, записанные русскими словами; отрицательные значения задаются словом `минус`.
- Операции: `плюс`, `минус`, `умножить`, `делить`.
- Несколько операций в одном выражении с учётом приоритета.
- Обычные и вложенные скобки, обозначаемые одним словом `скобка`.
- Унарный минус, в том числе перед скобками и несколько минусов подряд.
- Результат — целое число от **−9999 до 9999**, записанное словами.
- Деление допускается только при **целочисленном результате**. Деление на ноль вызывает ошибку.
- После ошибки ввода программа не завершается: можно ввести новое выражение. Команда `конец` завершает работу.

**Пока не поддерживаются:** дробные результаты и неявное умножение (например, `пять скобка три плюс два скобка` вместо явного `пять умножить скобка ...`).

## Архитектура проекта

Каждый модуль выполняет отдельный этап обработки. Данные передаются между функциями через возвращаемые значения.

```text
text-calculator/
├── main.py                # Ввод, вывод и объединение модулей
├── number_parser.py       # Русские числительные → int
├── number_formatter.py    # int → русские числительные
├── expression_parser.py   # Текстовое выражение → список токенов
├── rpn.py                 # Инфиксная запись → ОПН
├── calculator.py          # Вычисление ОПН
├── tests/                 # Автоматические тесты pytest
└── README.md
```

**Общий путь обработки:**

```text
"скобка пять плюс три скобка умножить минус два"
              ↓ parse_expression()
['(', 5, '+', 3, ')', '*', 'NEG', 2]
              ↓ to_rpn()
[5, 3, '+', 2, 'NEG', '*']
              ↓ evaluate_rpn()
-16
              ↓ number_format()
"минус шестнадцать"
```

## Описание модулей

### 1. `number_parser.py` — преобразование слов в число

**Основная функция:** `parse_number(text)`

- **Вход:** строка `text` (`str`) с русским числительным.
- **Выход:** целое число (`int`) от 0 до 99.
- **Пример:** `parse_number("сорок пять")` → `45`.

**Словари:**

| Имя | Назначение |
|---|---|
| `UNITS` | Единицы от нуля до девяти |
| `TEENS` | Особые названия чисел от десяти до девятнадцати |
| `TENS` | Десятки от двадцати до девяноста |

**Принцип работы:** функция распознаёт слова числительного по словарям и проверяет допустимость сочетания частей числа. При некорректной записи вызывается `ValueError`.

### 2. `number_formatter.py` — преобразование числа в слова

**Основная функция:** `number_format(number)`

- **Вход:** целое число `number` (`int`).
- **Выход:** строка (`str`) с русской записью числа.
- **Диапазон:** от −9999 до 9999 включительно.
- **Пример:** `number_format(-579)` → `"минус пятьсот семьдесят девять"`.

**Основные переменные:**

| Имя | Назначение |
|---|---|
| `number` | Необработанная часть числа, уменьшается после выделения разряда |
| `result` | Список слов будущего ответа |
| `divisor` | Значение текущего разряда: 1000, 100, 10 или 1 |
| `digit` | Цифра, выделенная из текущего разряда |
| `key` | Значение разряда для выбора соответствующего числительного |

**Принцип работы:** отдельно обрабатываются отрицательный знак, ноль и числа от 10 до 19. Для остальных чисел последовательно выделяются разряды через `//`, находятся соответствующие слова, а остаток числа определяется через `%`. Готовые слова объединяются с помощью `' '.join(result)`.

Если результат выходит за поддерживаемый диапазон, функция сообщает об ошибке, а не пытается сформировать неправильный ответ.

### 3. `expression_parser.py` — разбор выражения

**Основная функция:** `parse_expression(expression)`

- **Вход:** выражение на русском языке (`str`).
- **Выход:** список чисел и математических токенов (`list`).
- **Пример:** `parse_expression("пять минус минус три")` → `[5, '-', 'NEG', 3]`.

**Основные переменные и структуры:**

| Имя | Назначение |
|---|---|
| `words` | Слова исходной строки после `split()` |
| `tokens` | Список распознанных чисел, операторов и скобок |
| `number_words` | Буфер слов, составляющих одно число (например, `['двадцать', 'пять']`) |
| `expect_number` | Состояние парсера: ожидается операнд или оператор |
| `bracket_depth` | Количество открытых, но ещё не закрытых скобок |
| `OPERATORS` | Соответствие русских названий операций знакам `+`, `-`, `*`, `/` |
| `finish_number()` | Вложенная функция: преобразует накопленное числительное в `int`, добавляет его в `tokens` и очищает буфер |

**Принцип работы:** парсер перебирает слова, накапливает многословные числа и завершает их обработку при встрече оператора или скобки. Переменная `expect_number` помогает проверить порядок элементов и различить бинарное вычитание (`-`) и унарное изменение знака (`NEG`).

Слово `скобка` интерпретируется как `(`, когда ожидается операнд, и как `)`, когда ожидается оператор. Переменная `bracket_depth` контролирует баланс скобок. Это правило позволяет обрабатывать вложенные скобки при **явно записанных операциях**.

**Пример:**

```text
скобка пять плюс три скобка умножить два
        ↓
['(', 5, '+', 3, ')', '*', 2]
```

Некорректный порядок слов, незаконченные выражения и несбалансированные скобки приводят к `ValueError`.

### 4. `rpn.py` — преобразование в обратную польскую нотацию

**Основная функция:** `to_rpn(tokens)`

- **Вход:** список токенов в обычной (инфиксной) записи.
- **Выход:** список токенов в обратной польской нотации (ОПН).
- **Пример:** `[5, '+', 3, '*', 2]` → `[5, 3, 2, '*', '+']`.

**Основные переменные и структуры:**

| Имя | Назначение |
|---|---|
| `PRECEDENCE` | Приоритеты операторов: `+`/`-` — 1, `*`/`/` — 2, `NEG` — 3 |
| `RIGHT_ASSOCIATIVE` | Множество правоассоциативных операторов (`NEG`) |
| `operators` | Стек ожидающих обработки операторов и открывающих скобок |
| `output` | Формируемая последовательность ОПН |
| `token` | Текущий элемент входного списка |

**Алгоритм:** используется *сортировочная станция* (shunting-yard). Числа сразу добавляются в `output`, операторы временно хранятся в стеке `operators`. Перед помещением нового оператора из стека извлекаются операторы с большим приоритетом, а при равном приоритете учитывается ассоциативность. Скобки управляют порядком извлечения и в итоговую ОПН не попадают.

`NEG` правоассоциативен: это позволяет корректно преобразовывать последовательные унарные минусы, например `['NEG', 'NEG', 5]` → `[5, 'NEG', 'NEG']`.

### 5. `calculator.py` — вычисление ОПН

**Основная функция:** `evaluate_rpn(tokens)`

- **Вход:** список токенов в ОПН.
- **Выход:** одно целое число (`int`).
- **Пример:** `[5, 3, 2, '*', '+']` → `11`.

**Основные переменные:**

| Имя | Назначение |
|---|---|
| `stack` | Стек чисел и промежуточных результатов |
| `token` | Текущий элемент ОПН |
| `a`, `b` | Извлекаемые операнды: `a` — правый, `b` — левый |

**Принцип работы:** числа помещаются в стек. Бинарные операторы извлекают два последних числа и возвращают результат в стек; `NEG` извлекает только одно число и меняет его знак. Для вычитания и деления сохраняется порядок операндов: `b - a` и `b / a`.

Перед операцией проверяется достаточность операндов. Деление на ноль вызывает `ZeroDivisionError`, а деление с нецелым результатом — `ValueError`. После обработки всей ОПН в стеке должен остаться ровно один элемент.

### 6. `main.py` — интерфейс программы

**Основная функция:** `calc(expression)`

- **Вход:** текстовое выражение (`str`).
- **Выход:** ответ словами (`str`).
- **Пример:** `calc("двадцать пять плюс тринадцать")` → `"тридцать восемь"`.

`calc()` последовательно вызывает `parse_expression()`, `to_rpn()`, `evaluate_rpn()` и `number_format()`. Пользовательский интерфейс работает в цикле `while True`: принимает выражения до команды `конец`. Исключения `ValueError` и `ZeroDivisionError` перехватываются, поэтому после ошибки программа предлагает ввести следующее выражение.

## Проверка корректности

Для автоматического тестирования используется `pytest`. Тесты отдельно проверяют преобразование чисел, разбор выражений, скобки, унарный минус, приоритеты операций, ОПН, вычисления и обработку ошибок. После изменений в алгоритмах запускается весь набор тестов, чтобы проверить, не нарушена ли ранее работающая функциональность.

**Запуск программы:**

```bash
python main.py
```

**Запуск всех тестов:**

```bash
python -m pytest -v
```

**Примеры:**

```text
пять плюс три                                → восемь
пять минус минус три                         → восемь
скобка пять плюс три скобка умножить два     → шестнадцать
минус скобка пять плюс три скобка            → минус восемь
семь делить два                              → ошибка: не делится нацело
пять делить ноль                             → ошибка: деление на ноль
```
